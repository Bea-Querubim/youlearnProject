## 🚀 Get Started - Como rodar este projeto no VS Code
Siga este passo a passo para clonar e rodar o projeto localmente:

---

### ✅ Pré-requisitos
Antes de começar, você precisa ter instalado:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Dart (já vem com o Flutter)
- [Visual Studio Code](https://code.visualstudio.com/)
- Extensões do VS Code:
  - Flutter
  - Dart

> Verifique se está tudo certo com:
```bash
flutter doctor
```

---
# 📁 Instalando as dependências

Apos clonar o repo, rode:
```bash
flutter pub get
```
---
📱 Executando o app
```bash
flutter run
```

Ou ctrl + f5 para o modo debug(run) (usado quando paa debug no celular via USB)
